# The padding leaves

**Line:** The padding leaves — the twenty placeholder cards, their text entries and every test that holds only on them leave the branch, the collection panel's wheel test among them, and the suite passes on the Nomadic content alone. Doc-impact: none.

**Spec:** `workflow/BRANCH.md`, _The padding_. No sentence of `docs/` changes: every page states the behaviour the branch built, which holds whatever the content. No player-facing text.

**Doc-impact:** none — the padding never stood on a page.

**Scope:**

- In: the twenty cards, their forty text entries and the deck's twenty copies leave `src/content/nomadic.ts` and `src/ui/text.ts`, the content standing as it stood before the branch.
- In: every test that holds only on the padding leaves with it, whole. Foreseen: the collection panel's wheel test the wheel line adds to `e2e/collection.spec.ts`. Any other a line of the branch named in its hand-back is listed here before this line ships. Their leaving is decided: the behaviour each proved is promised all the same, and the Stone Age rung carries the spec that proves the collection scrolls on real content.
- In: the suite passes on CI on the Nomadic content alone.
- Out: any test that holds on real content, the browse's and the windows' among them, which stay; any change to what the branch built.
- Corner: a campaign a browser kept on the branch owns placeholder cards the content no longer holds; the save reader answers it as it answers any id the content no longer holds (`docs/META.md`). Nothing is added for it.

**Traps:**

- The padding's own dossier, `workflow/board/the-content-is-padded.md`, names the ids, the entries and the deck's list; its commit is the one this line undoes, and `git show` on it is the list of what goes.
- A spec whose seed search moved with the padding moves back by itself: every search reads the rules. One that the padding's line changed beyond its seed is named in that line's hand-back and is put back here.
- Deleting a test is a design change made with the user (`DOGMAS.md`, _Testing_); the tests this line deletes are the ones listed above, decided when the branch was cut, and no other.

**Plan:**

1. `src/content/nomadic.ts`, `src/ui/text.ts`: the padding out. The tests listed above, out. Leaves standing: the content as it stood before the branch, the coherence test passing.
2. `workflow/BRANCH.md`: the line deleted, this file with it.

**Verify:** `npm run check`, `npm test`, `npm run lint`; the proof spec `npx playwright test e2e/collection.spec.ts`, which holds on the Nomadic content alone once the wheel test has left it. The rest is CI's on the push of the branch, the whole suite.

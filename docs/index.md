# Docs

What the game **is**: the standing design. Not a journal of how it came to be — git holds history, [`../CHANGELOG.md`](../CHANGELOG.md) holds what players were told; how the project is built is [`../DOGMAS.md`](../DOGMAS.md), and what is next is [`../workflow/`](../workflow/BOARD.md). Every page is reachable from here; a page earns existence only when the summary line pointing to it is much shorter than what it holds.

- [`DESIGN.md`](DESIGN.md) — the game in broad strokes: the pitch, launching a chronicle, the meta, scope. Names the other three design pages; the four are the spec, every section marked decided or provisional, its rationale inline.
- [`INTERFACE.md`](INTERFACE.md) — how any screen is worked: the menu, Controls, the debug console, the three presses, what stands over what.
- [`CHRONICLE.md`](CHRONICLE.md) — the rules a chronicle is played by: the turn, sight, cards, population, the map, units, events.
- [`CHRONICLE-SCREEN.md`](CHRONICLE-SCREEN.md) — how the chronicle is shown and worked on its screen: the chronicle screen, the resource bar, the yield overlay.
- [`ages/`](ages/NOMADIC.md) — one content page per age, under the design pages' legend: what the age is made of — its settle, land, units, cards, events, capstone and camps — with no number on it. [`ages/NOMADIC.md`](ages/NOMADIC.md) is the first.
- [`GLOSSARY.md`](GLOSSARY.md) — the closed vocabulary of gameplay terms and the synonyms each one forbids.
- [`ASSET-SOURCES.md`](ASSET-SOURCES.md) — where free art, sound, music and fonts come from, with each site's licence terms. Browsed for creativity fuel; used when the look is built.

Domain pages (standing knowledge of the genre, the platform, the audience — each claim naming its source) are added here when there is a domain to describe.

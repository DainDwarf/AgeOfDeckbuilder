# Asset sources

Where free art, sound, music and fonts come from when the look is built. [The dogmas](../DOGMAS.md) set the constraints; the paid packs the look is painted from are [`LOOK.md`](LOOK.md)'s.

Licence shorthand: **CC0** needs nothing; **CC BY** needs the author credited in the licence file; **CC BY-SA** needs the same, and a recolour or a crop of the asset stays BY-SA, the game's code untouched; **OFL** is the open font licence, fonts embed freely; **Apache 2.0** and **MIT** ask for the licence's text beside the files and no credit, Apache 2.0 also that a changed file says it was changed. **NC**, **ND** and the **GPL** are out; a pack whose files may not be handed out on their own is kept in the store, never in the repository. Anything else is read per pack.

## Art

- [Kenney](https://kenney.nl/assets) — the deepest free supply, everything CC0. Strong on flat vector, UI and board-game packs; thinner on hex-strategy pixel art, though hex packs exist.
- [OpenGameArt](https://opengameart.org) — community archive, mixed quality and licences. Filter by licence before browsing.
- [itch.io free game assets](https://itch.io/game-assets/free) — many small pixel-art packs by individual artists. Licences vary per pack; several forbid redistributing the raw files.
- [Game-icons.net](https://game-icons.net) — several thousand flat monochrome icons, CC BY 3.0, deep in objects and thin in plain forms. The symbols that are objects.
- [Material Design Icons](https://pictogrammers.com/library/mdi/) — the Pictogrammers' set, several thousand filled interface icons, Apache 2.0 but for its Brand / Logos category, each icon's page naming its author and its categories. The symbols that are plain forms.
- [Iconify](https://icon-sets.iconify.design) — one search across the open icon sets, the two above among them, each set's licence beside it. A place to search and never the licence's source: a set's own licence file is what is read.

## Sound

- [Freesound](https://freesound.org) — sound effects, CC0 and CC BY, filterable by licence.
- [Kenney audio](https://kenney.nl/assets/category:Audio) — CC0 UI and impact sounds.

## Music

- [Incompetech](https://incompetech.com/music/royalty-free/) — Kevin MacLeod's catalogue, CC BY with the attribution string the site generates per title.
- [OpenGameArt music](https://opengameart.org/art-search-advanced?field_art_type_tid%5B%5D=12) — many CC0 and CC BY loops.

## Fonts

- [Google Fonts](https://fonts.google.com) — OFL faces.
- [Adobe's Source fonts](https://github.com/adobe-fonts) — OFL; the built files, WOFF2 among them, sit on each repository's `release` branch beside the licence.
